電気通信大学 旧シラバス PDF 結合ツール

2004〜2009年度の旧シラバスのPDFを電気通信大学の公式アーカイブから取得し、年度・課程別のしおり付きPDFに結合するPythonスクリプトです。

Pythonスクリプトをダウンロード

実行方法

ダウンロードしたファイルのあるフォルダで実行してください。Python 3とインターネット接続が必要です。

python3 -m pip install pypdf
python3 uec_syllabus_appendix.py

出力ファイルは uec_syllabus_2004-2009.pdf です。途中で取得に失敗した場合は、再実行すると取得済みのPDFを再利用します。
